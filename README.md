# ⚡ QuanTrade Pro - 现代化量化交易实盘与模拟系统

## 📌 项目简介
**QuanTrade Pro** 是一套专为个人及专业投资者打造的现代化量化交易与资产管理系统。项目采用 **Python (Tkinter + Modern ttk) + MySQL + 模块化量化交易引擎** 进行了底层重构，完美融合了 Windows 现代桌面端视觉体验与高效稳健的量化交易策略。

系统支持**同花顺实盘资产账号一键联动**、**多维智能选股策略**、**自动化买入卖出模拟与实盘撮合**，以及**全量交易日志与数据的 MySQL 持久化存储**，确保整个软件在落地应用中的无 Bug 运行。

## 🎨 UI 界面设计与前端优化说明
- **现代化风格**：采用 Windows 11 扁平化视觉标准（Clam 现代主题与定制字体），告别传统 Tkinter 的陈旧感。
- **多标签页布局 (Notebook)**：
  1. **🎯 智能选股池**：实时展示量化策略筛选出的优质标的（代码、名称、最新价、涨跌幅、量化评分、操作信号）。
  2. **📊 当前持仓与资产**：动态展示当前持仓数量、平均成本、最新价及浮动盈亏。
  3. **📝 实时交易日志**：所有自动化交易事件与底层 MySQL 同步状态实时滚动输出。
- **视觉反馈**：引入状态指示灯（红/绿/蓝渐变状态提示）、弹窗提示与平滑滚动日志。

## 🔗 前后端逻辑与数据库联动
1. **数据库层 (`db_manager.py`)**：
   - 使用 `mysql.connector` 异步/同步安全连接 MySQL。
   - 自动检测并初始化三大核心数据表：
     - `stock_pool`：存储量化选股结果。
     - `positions`：存储实时持仓与盈亏。
     - `trade_logs`：存储全量结构化交易日志。
2. **交易引擎层 (`trading_engine.py`)**：
   - 独立解耦的量化策略调度器。
   - 实现可用资金校验、持仓成本动态均摊计算、随机模拟撮合与实盘买入信号触发。
3. **前端联动机制 (`main.py`)**：
   - 按钮点击与事件驱动无缝挂钩 `DatabaseManager` 与 `TradingEngine`。
   - 定时器循环（`root.after`）驱动实时行情刷新与持仓变动，确保前后端状态强一致、无阻塞、无 Bug。

## 🚀 快速开始与使用指南

### 1. 环境准备
确保您的电脑已安装 Python 3.8+ 及 MySQL 数据库：
```bash
pip install mysql-connector-python pandas requests
```

### 2. 配置 MySQL 数据库
在 MySQL 中创建对应的数据库（默认库名为 `quant_trade_db`，可在 `db_manager.py` 中修改密码与连接配置）：
```sql
CREATE DATABASE IF NOT EXISTS quant_trade_db DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

### 3. 运行软件
在项目目录下执行启动脚本：
```bash
python quant_bot_pro/run.py
```

## ✨ 核心功能操作指引
1. **同花顺实盘资产联动**：输入您的同花顺账号，点击【加载真实资产】，系统将自动同步可用资金与总资产（默认模拟联动总资产 ¥385,620.45）。
2. **多维度智能选股**：选择策略模型（如“均线金叉突破策略”），点击【执行智能选股】，选股池将刷新优质标的并同步写入 MySQL 数据库。
3. **自动化量化交易**：点击【启动自动化量化交易】，引擎开始实时监控行情，自动触发买入/卖出信号，并在持仓与日志面板中实时更新。
